# 為替・コモディティ 5分足アーカイブ

主要通貨(対円・対ドル)と主要コモディティの5分足を毎日記録している。

**📊 閲覧用サイト: https://al00000000.github.io/fx-commodity-5min/**
([売買代金ランキング/その他](https://al00000000.github.io/kabutan-ranking/) の「為替・商品」タブからも開ける)

## 記録している銘柄(26)

| 分類 | 銘柄 |
|---|---|
| 対円 | ドル円 / ユーロ円 / ポンド円 / 豪ドル円 / NZドル円 / カナダドル円 / スイスフラン円 / 人民元円 |
| 対ドル | ユーロドル / ポンドドル / 豪ドル / NZドル / カナダドル / スイスフラン / 人民元 / ドル指数(DXY) |
| 貴金属 | 金 / 銀 / プラチナ / 銅 |
| エネルギー | WTI原油 / ブレント原油 / 天然ガス |
| 穀物 | 小麦 / トウモロコシ / 大豆 |

銘柄を増減したいときは `fetch_fx5min.py` の `SYMBOLS` を編集する。

## データ形式

`docs/data/YYYY-MM-DD.json.gz` を gzip 展開すると:

```json
{"date":"2026-09-02","generated":"...","bars":{"USDJPY=X":[["00:00",160.066,160.09,160.04,160.07,0], ...]}}
```

1本 = `[時刻(JST), 始値, 高値, 安値, 終値, 出来高]`。為替に出来高は無いので0が入る。
為替は1日288本(5分×24時間)、コモディティは先物の取引時間ぶん。

```python
import gzip, json
with gzip.open("docs/data/2026-09-02.json.gz", "rt", encoding="utf-8") as f:
    day = json.load(f)
bars = day["bars"]["USDJPY=X"]
```

## 自動実行

Windowsタスクスケジューラ `\StockAutomation\fx-5min`(毎日 07:00)。
実体は `C:\Users\yt\automation\run_task.py` + `tasks.json` の汎用ランナー。

## 仕様上の注意

- Yahoo Finance のチャートAPIは `range=1mo&interval=5m` で **約30日ぶんの5分足**を返す。
  そのため取得に失敗した日やPCが落ちていた日があっても、**30日以内に一度動けば自動で埋め戻る**
  (株探の5営業日制限と違い余裕がある)。
- 日付は **JST基準**でバケツ分けしている。為替はJSTの0時をまたいで連続して動くため、
  日付の切れ目は市場の区切りとは一致しない。
- コモディティは**各限月の先物**(例: Gold Dec 26)。限月が変わると価格が不連続になることがある。
- 土日は為替・先物とも動かないのでファイルが作られない(または本数が極端に少ない)。
